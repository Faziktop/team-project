**Recipe Collection** — это современное, высокопроизводительное веб-приложение для создания, поиска, масштабирования и пошагового приготовления кулинарных блюд. 

Проект прошёл полный рефакторинг и модернизацию архитектуры, поднявшись с базового прототипа до **полноценного продакшен-уровня** с богатым набором интерактивных функций.

---

## 🌟 Ключевые возможности

### 🎨 1. Премиальный дизайн и адаптивность (UI/UX)
- **Тёмная и светлая тема (Dark / Light Mode)** с автоопределением системных настроек и сохранением выбора.
- **Современная дизайн-система**: шрифты Montserrat / Inter, микроанимации, карточки блюд с эффектом 3D-lift.
- **100% мобильная адаптивность**: удобное бургер-меню и адаптивные сетки под смартфоны и планшеты.
- **Всплывающие Toast-уведомления** с автоматическим скрытием.

### ⚖️ 2. Динамический масштабировщик порций (Servings Scaler)
- Умный парсинг строк ингредиентов (граммовки, штуки, ложки, миллилитры).
- Кнопки `[ - ]` и `[ + ]` в реальном времени пересчитывают количества всех ингредиентов под выбранное количество порций.

### 👨‍🍳 3. Пошаговый «Режим шеф-повара» (Cooking Mode)
- Полноэкранный фокус-режим для готовки на кухне с планшета или смартфона.
- **Встроенные таймеры шагов**: система автоматически распознает указание времени в тексте шагов (*«варить 9 минут»*) и запускает обратный отсчёт.
- **Синтезированный звуковой сигнал (Web Audio API)**: приятный кулинарный колокольчик по завершении таймера без сторонних аудиофайлов.
- Поддержка навигации клавишами со стрелками `[←]` и `[→]`.

### 🛒 4. Интерактивный список покупок (Shopping List)
- Чекбоксы ингредиентов прямо в карточке рецепта.
- Кнопка «В список покупок» сохраняет недостающие ингредиенты в персональный список.
- Возможность вычеркивать купленное, добавлять свои заметки, выводить список на печать или копировать в буфер обмена для отправки в Telegram/WhatsApp.

### ⭐ 5. Рейтинги, отзывы и избранное
- Интерактивный виджет оценки (1–5 звёзд) и отзывы пользователей.
- Расчёт среднего рейтинга блюда.
- AJAX-добавление в избранное без перезагрузки страницы.

### 🔍 6. Продвинутый поиск, фильтрация и сортировка
- Мгновенный поиск по названию, ингредиентам, кухне и описанию.
- Фильтры по категориям, кухням мира, сложности и времени готовки.
- Сортировка по новизне, популярности, скорости и дате.

### 👑 7. Панель администратора (Admin Dashboard)
- Аналитические карточки KPI: общее число пользователей, рецептов, отзывов и закладок.
- Управление рецептами, пользователями и модерация отзывов.

### 🔌 8. RESTful API (JSON)
- `/api/recipes` — каталог с пагинацией и фильтрами.
- `/api/recipes/<id>` — детальный JSON со всеми ингредиентами, шагами и отзывами.
- `/api/stats` — общая статистика.

## 🚀 Быстрый старт

### Локальный запуск:
```bash
cd recipe-collection
python3 -m venv venv
source venv/bin/activate  # на Windows: venv\Scripts\activate
pip install -r requirements.txt
python app.py
```
Откройте браузер: **`http://localhost:5000`**

### Запуск в Docker:
```bash
docker-compose up --build
```
